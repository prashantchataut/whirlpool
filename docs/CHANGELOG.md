# Changelog

## 0.1.0

First Whirlpool release. Forked from Muelle Native 0.2.0.

- Renamed to Whirlpool: crates, binaries (`whirlpool.exe`, `whirlpool-settings.exe`), config folder, window classes, mutexes, registry keys, installer.
- New water theme across the dock, menus, labels, mascot and the settings app; new vortex icon.
- Settings: new palette, vortex brand mark, tinted nav selection with an accent bar, waterline under page titles.
- First run copies settings from an existing Muelle install.
- New website in `site/`, new docs.
